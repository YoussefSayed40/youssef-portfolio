# Yusuf Sayed — Data Portfolio

React + Vite portfolio for Data Analytics / Data Science.

## Main feature

The Projects section reads public repositories from the GitHub API for:

`YoussefSayed40`

So new public repositories can appear automatically without manually adding project cards.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Import this repository into Vercel. Every push to the portfolio repository can trigger a new deployment.

## Customize

- Replace the email placeholder in `src/main.jsx`.
- Add a CV URL if/when you have the final PDF.
- Update the About section as your experience grows.
